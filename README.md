# Build Your Own Custom PC Website

موقع ويب احترافي لشركة "Build Your Own Custom PC" - وجهتك الموثوقة لشراء الحواسيب الجاهزة وقطع الكمبيوتر عالية الجودة.

## 🌟 نظرة عامة

هذا المشروع عبارة عن موقع ويب متجاوب ومتعدد اللغات (العربية) مصمم لشركة متخصصة في بيع وتجميع أجهزة الكمبيوتر المخصصة. يتميز الموقع بتصميم عصري وجذاب مع خلفية متحركة وتأثيرات بصرية متقدمة.

## ✨ المميزات

### 🎨 التصميم
- **تصميم عصري وجذاب** مع ألوان متناسقة وتدرجات لونية جميلة
- **خلفية متحركة** مع تأثيرات تدرج لوني مستمر
- **تأثيرات بصرية متقدمة** مع `backdrop-filter` وحركات سلسة
- **أيقونات Font Awesome** للعناصر المختلفة
- **تأثيرات hover** وتحركات تفاعلية

### 📱 التجاوب
- **متجاوب تماماً** مع جميع أحجام الشاشات
- **قائمة هامبورغر** للهواتف المحمولة والأجهزة اللوحية
- **تخطيط مرن** باستخدام CSS Grid و Flexbox
- **تحسين للهواتف** مع أحجام خطوط مناسبة

### 🌐 الدعم العربي
- **اتجاه النص من اليمين لليسار (RTL)**
- **خط Cairo العربي** الجميل والواضح
- **تنسيق مناسب** للنصوص العربية
- **محتوى باللغة العربية** بالكامل

### ⚡ التفاعل
- **قائمة تنقل ثابتة** مع تأثيرات التمرير
- **روابط سلسة** بين الأقسام المختلفة
- **تأثيرات بصرية** عند التمرير والتفاعل
- **قائمة هامبورغر تفاعلية** للهواتف

## 🚀 كيفية الاستخدام

### المتطلبات
- متصفح ويب حديث يدعم CSS3 و HTML5
- لا توجد متطلبات إضافية للمشروع

### التشغيل
1. **تحميل الملفات**: قم بتحميل جميع الملفات إلى مجلد واحد
2. **فتح الموقع**: افتح ملف `index.html` في أي متصفح ويب
3. **الاستمتاع**: الموقع جاهز للعرض والاستخدام!

### التخصيص
- **الألوان**: يمكن تعديل الألوان من خلال متغيرات CSS
- **المحتوى**: يمكن تعديل النصوص في ملف `index.html`
- **التخطيط**: يمكن تعديل التخطيط في ملف `styles.css`

## 🔧 التطوير والتخصيص

### إضافة أقسام جديدة
```html
<section id="new-section" class="new-section">
    <div class="container">
        <div class="section-header">
            <h2>عنوان القسم الجديد</h2>
            <div class="section-divider"></div>
        </div>
        <!-- محتوى القسم -->
    </div>
</section>
```

### إضافة أنماط جديدة
```css
.new-section {
    background: rgba(255, 255, 255, 0.95);
    backdrop-filter: blur(10px);
}

.new-section h2 {
    color: #2c3e50;
    font-size: 2.5rem;
}
```

### إضافة عضو جديد للفريق
```html
<div class="team-member">
    <div class="member-avatar">
        <i class="fas fa-user-tie"></i>
    </div>
    <h3>اسم العضو</h3>
    <p>المنصب</p>
    <div class="member-social">
        <a href="#"><i class="fab fa-linkedin"></i></a>
        <a href="#"><i class="fab fa-github"></i></a>
    </div>
</div>
```
